# Design dos 3 mapas

## 1) Cidade Destruída (`CityDestroyed`)
- Ruas principais com carros queimados (cobertura média).
- Prédios colapsados para combate vertical leve.
- Praça central como ponto estratégico de alto risco.

## 2) Base Militar (`MilitaryBase`)
- Corredores entre hangares para combate tático.
- Containers e barricadas para cobertura curta.
- Torre de vigia como posição dominante.

## 3) Floresta de Guerra (`WarForest`)
- Árvores densas e troncos derrubados para camuflagem.
- Acampamentos e trincheiras como choke points.
- Clareira central para objetivos de captura.

## Regras de layout
- Sempre ter rotas alternativas para flanqueamento.
- Distribuir coberturas em distância curta, média e longa.
- Evitar linhas de visão longas demais em mobile.
